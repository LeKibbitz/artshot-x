# ArtShot X · 0.7.0 Preview 1

Première preview avec un cœur Rust et une interface Tauri partagés entre macOS et Windows 11.

## Téléchargements

| Système | Installateur |
| --- | --- |
| macOS 14 ou supérieur, Apple Silicon | `ArtShot-X-0.7.0-macOS-arm64.dmg` |
| Windows 11, x64 | `ArtShot-X-0.7.0-Windows11-x64-setup.exe` |

Les fichiers sont joints à cette release, avec `SHA256SUMS.txt`. Aucun outil de développement n’est nécessaire. Sur Mac, ouvrir le DMG puis glisser l’application dans Applications. Sur Windows, lancer le programme d’installation ; il prend en charge WebView2 si nécessaire.

La nouvelle application s’appelle **ArtShot X Preview**. Quitter l’ancienne ArtShot X avant de la lancer pour libérer les raccourcis. Sa bibliothèque est séparée ; les captures de l’ancienne version restent à leur emplacement.

## Fonctions

Capture plein écran ou zone ajustable, annotation PNG, étapes numérotées, capture défilante avec aperçu complet, vidéo avec caméra et deux sources audio, télécommande flottante, pause/reprise, retrait de passages, volumes séparés et export MP4. La caméra propose rond, carré, rectangle arrondi et ovale vertical, avec taille, position et zoom centré 1–3×.

Raccourcis : **⌘⌥⇧5/6/7** sur Mac ; **Ctrl+Alt+Maj+5/6/7** sur Windows. Le 7 ouvre la sélection, puis les actions Photo/Défilement/Vidéo. Pendant un enregistrement, il rappelle la télécommande.

## Validation de cette preview

- 21 tests Rust et 4 tests TypeScript réussis sur macOS ; 5 tests CPU supplémentaires pour la synchronisation audio Windows.
- Compilation de l’application Windows x64 et création de son installateur NSIS réussies ; bibliothèques média et désinstallation incluses.
- DMG monté, signature locale vérifiée, application copiée depuis le DMG puis lancée sur Mac Apple Silicon.
- Capture plein écran réalisée par l’application installée : PNG de 3024 × 1964 pixels, enregistré dans la bibliothèque, avec vignette et actions Modifier/Enregistrer/Copier.
- Capture, pause/reprise et export macOS exercés via l’adaptateur natif ; exports synthétiques avec coupes, caméra, gains et événements vérifiés.

**Windows n’a pas encore été testé sur une machine physique.** Les essais externes doivent notamment vérifier les autorisations, le focus, le plein écran, les écrans multiples, la caméra, le défilement et la synchronisation audiovisuelle. Sur macOS, la capture plein écran du paquet distribué est validée ; les autres parcours nécessitent encore leur acceptation. Cette preview est destinée aux essais et ne prétend pas avoir passé l’acceptation finale sur les deux systèmes.

Le DMG utilise une **signature ad-hoc, sans notarisation Apple**. L’installateur Windows est **non signé**. Les systèmes peuvent donc afficher un avertissement lors de la première ouverture.
