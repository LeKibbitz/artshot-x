# ArtShot X · 0.7.1 Preview 1

Cette mise à jour corrige plusieurs régressions du parcours de capture de la preview Rust/Tauri.

- Barre compacte visible dès l’ouverture de la sélection ; zone déplaçable et huit poignées de redimensionnement. Photo, Défilement et Vidéo attendent la validation de la zone courante.
- Vignette avec quatre actions visibles : Supprimer, Modifier, Enregistrer et Copier. Une erreur de capture n’affiche plus une ancienne image comme si elle venait d’être prise.
- Fond de sélection renouvelé à chaque ouverture, sans réutilisation d’une ancienne page en cache.
- Capture défilante plus tolérante aux petits changements isolés, avec prise en charge d’un pied de page fixe. Aperçu intégral compact, progression et annulation. Le raccourci 7 rappelle une capture défilante déjà en cours.
- Sur Mac, la sélection reçoit explicitement les touches sans activer la bibliothèque. Un journal local borné consigne uniquement les raccourcis ArtShot enregistrés et l’ouverture/fermeture de ses fenêtres pour diagnostiquer les problèmes de déclenchement.

## Installateurs

- macOS 14+, Apple Silicon : `ArtShot-X-0.7.1-macOS-arm64.dmg`.
- Windows 11 x64 : `ArtShot-X-0.7.1-Windows11-x64-setup.exe`.

La bibliothèque locale existante est conservée. Quitter l’ancienne application avant le remplacement. Sur Mac, la signature ad-hoc de cette preview peut nécessiter le renouvellement de l’autorisation d’enregistrement d’écran. Le paquet Mac n’est pas notarisé et l’installateur Windows n’est pas signé.

## Vérification

24 tests Rust réussis, 4 tests géométriques TypeScript réussis et tests d’interface dans un navigateur avec IPC simulé : quatre actions dans 340 × 260, aperçu dans 280 × 440, sélection, ordre des commandes et gestion d’erreur.

Ces tests ne valident pas les raccourcis physiques ni le maintien du focus dans un navigateur natif. L’acceptation de ces parcours sur Mac reste en cours. Windows reste à faire tester sur une machine Windows 11 réelle.

Pour tester le défilement sur une page neutre : servir `desktop/test-fixtures/scroll.html` localement, sélectionner sa zone de contenu, choisir Défilement puis avancer par petits mouvements avec une courte pause. Une page répétitive ou un déplacement trop grand peut être refusé : conserver un chevauchement suffisant entre deux positions.
